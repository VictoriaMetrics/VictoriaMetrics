This section holds guides of how to set up and use VictoriaMetrics Anomaly Detection (or simply [`vmanomaly`](https://docs.victoriametrics.com/anomaly-detection/)) service, integrating it with different observability components.

Guides:

* [Choose a model for your metrics](https://docs.victoriametrics.com/anomaly-detection/guides/model-selection/): match your operational question to a model, try prepared examples, and copy a configuration.

* [Anomaly Detection & Alerting Setup](https://docs.victoriametrics.com/anomaly-detection/guides/guide-vmanomaly-vmalert/): connect anomaly detection results to vmalert, Alertmanager, and Grafana for alerting and investigation.
